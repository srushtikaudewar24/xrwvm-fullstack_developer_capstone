# Cars Dealership — Full-Stack Capstone Project

## Project Name
Cars Dealership — Full-Stack Web Application

## Project Description
A full-stack web application for browsing car dealerships,
viewing dealer details and customer reviews, filtering
dealerships by state, and submitting reviews.

## Features
- Dealer listings and state-based filtering
- Dealer details and customer reviews
- User registration, login, and logout
- Posting dealership reviews
- Car makes and models
- Review sentiment analysis

## Technologies
- Django and Python
- React and JavaScript
- Node.js
- SQLite and MongoDB
- REST APIs
- Docker and GitHub Actions
